## Ground rules given to every agent
- Target user: a student with basic computer skills. Aim: easy to use, easy to correct mistakes, fits real counter situations.
- Keep: the 3-step time control, the fictional sample data, the Candidate brief, "Restart sample shift". Vanilla HTML/CSS/JS with no build step, working offline.
- Every idea has an ID (UI-/WF-/RL-/BG-) and cites evidence from `00-walkthrough.md`.
- No app source file is modified during the audit.
